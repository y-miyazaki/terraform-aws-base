# Output format (github-issue-triage)

## Overview

Issue number, classification decision, confidence, labels added/removed, comments created vs updated.

## Changes

GitHub API side effects only (labels/comments). Interactive: list each `gh` mutation. Message run: list each file written to the message directory (`message.md`, `message_labels.json`) with the labels and comment it carries.

## Deferred

Items left for humans (e.g. awaiting answers, autofix not started).

## Session Metrics

Attempts, tools used, and any `gh` failures.
